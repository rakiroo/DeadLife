# DeadLife 🧟‍♂️

An interactive, gritty zombie apocalypse survival life simulator.

## Features
- **Dual-Pacing Loop**:
  - `Survive +1 Day`: Detailed daily survival, rationing, medical conditions, and immediate crisis encounters.
  - `Survive +1 Week`: Fast-paced tactical time jumps with 7-day chronological diary entries and major weekly events.
- **Realistic Survival Mechanics**:
  - Medical triage (arterial bleeding, wound sepsis, pathogen progression).
  - Hydration, nutrition, rainwater catchment, and barricade structural integrity.
  - Acoustic and light discipline (gunfire attracts roamers).
- **Mobile-First Experience**:
  - Optimized for mobile viewports and touch controls.
  - Ready for one-click deployment on Vercel.

## Running Locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

```bash
npx vercel
```
